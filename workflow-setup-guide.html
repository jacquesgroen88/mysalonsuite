MSS — Tour Preparation (24h Reminder)

24h Before Appointment

Navigate To

Automations › Workflows › + New Workflow › Start from Scratch

Name it: MSS — Tour Preparation (24h)

Trigger

  1. Click + Add Trigger
  2. Select Appointment Status
  3. Status: Confirmed
  4. Save trigger
Alternatively, use Appointment Date trigger set to 1 day before the appointment start time.

Actions (in order)

1
Wait Until 24 hours before appointment start time
(Use "Wait until relative time" → Appointment Date → minus 24h)
2
Send Email Template: MSS v2 - 02 Tour Preparation
This sends address, parking info, and what to expect.

MSS — Post-Tour, No Booking (Day After)

24h After Tour

Navigate To

Automations › Workflows › + New Workflow › Start from Scratch

Name it: MSS — Post-Tour No Booking

Trigger

  1. Click + Add Trigger
  2. Select Appointment Status
  3. Status: Completed (or Showed)
  4. Save trigger

Actions (in order)

1
Wait 24 hours
2
If/Else Condition Check if tag lease-signed exists
If YES → Stop (they already booked)
If NO → continue to next action
3
Send Email (NO branch only) Template: MSS v2 - 03 Profit Visualization
Subject: What could you really earn, {{contact.first_name}}?
4
Wait 4 days
5
Send Email Template: MSS v1 - 09 Evergreen Security
6
Wait 5 days
7
Send Email Template: MSS v1 - 11 Evergreen Client Experience
8
Wait 5 days
9
Send Email Template: MSS v1 - 13 Evergreen Final Push
Stop trigger: Add a workflow goal or stop event tied to the lease-signed tag. When that tag is added (i.e. they sign), the contact exits this workflow automatically.

MSS — Member Onboarding

New Member / Lease Signed

Navigate To

Automations › Workflows › + New Workflow › Start from Scratch

Name it: MSS — Member Onboarding

Trigger

  1. Click + Add Trigger
  2. Select Tag Added
  3. Tag: lease-signed
  4. Save trigger
When Stacey marks a member as signed, she adds the lease-signed tag to their GHL contact. That fires this workflow instantly.

Actions (in order)

1
Send Email Template: MSS v2 - 00 Member Onboarding
Contains: checklist, app downloads, handbook, Facebook group link
2
Wait 7 days
3
Send Email Template: MSS v1 - 14 Review Request
4
Wait 5 days
5
Send Email Template: MSS v1 - 15 Review Google
One-time setup: Create a GHL tag called lease-signed (Contacts → Tags → New Tag). Stacey applies it manually when a lease is executed. Rachel can also create a Pipeline stage that auto-tags on stage change.

Remaining Before Going Live

  1. Calendly URL — Once Rachel/Stacey provides it, update template MSS v2 - 01 Tour Requested to replace {{contact.calendly_url}} with the real link (or set it as a default value for the Calendly URL custom field).
  2. Form field mapping — In the Book-a-Tour form settings, map the time-preference question to the Preferred Tour Time custom field.
  3. Create tag lease-signed — Contacts → Tags in GHL.
  4. Test submission — Submit the form with a test contact, confirm Workflow 1 fires and email arrives.
  5. Publish workflows — Once tested, toggle each from Draft → Published.
